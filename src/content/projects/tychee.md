## What it is
Tychee is a **card tokenization SDK and rewards platform** built on Stellar's Soroban smart contracts. Card data is **encrypted locally** and only encrypted payloads go on-chain, for fast integration and user-owned security.

## Features
- On-chain encrypted card storage, with keys derived from the user's Stellar key.
- Per-network card validation (Luhn plus card-length rules).
- A points and rewards system for users and merchants.
- Optional gasless transactions.
- An example rewards dApp.
